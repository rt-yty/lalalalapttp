# О!дин запрос — React-интерфейс

React 19, TypeScript и Vite. Вход или регистрация обязательны до использования приложения. После входа доступны диалог, варианты дороги и отелей, выбранный план, события с городами и датами, настоящая Google Maps, история и предпочтения аккаунта. Компактный экран планирования заменяет прежний декоративный City Atlas.

## Запуск

```sh
npm ci
npm run build
```

FastAPI раздаёт `frontend/dist`. Для разработки API на `127.0.0.1:8765` и `npm run dev`: прокси `/api` сохраняет Host для проверки Origin.

## Проверки

```sh
npm test
npx playwright install chromium
npm run test:e2e
REAL_BASE_URL=http://127.0.0.1:8780 node e2e/real-smoke.mjs
```

Последняя команда запускается явно: проверяет обязательный вход, создаёт тестовый аккаунт, отправляет общий запрос о концерте для уточнений и восстанавливает разговор в другом браузере. Затем проверяет выход и настоящий 401. Нужен сервер с `auth_required:true`; отчёт и снимки сохраняются в `artifacts/v3/`. Поиск внешних предложений, письма, бронирования и платежи не выполняются. Тестовые учётные данные не записываются в отчёт.

## Поведение

- Кнопка «Оформить» доступна для полного подходящего сохранённого плана и только отмечает его в интерфейсе. Она не отправляет новый запрос, не создаёт заказ, не открывает оплату и не утверждает, что поездка забронирована.
- Карта использует настоящую Google Maps. Координаты берутся только из ответа сервера; при их отсутствии применяется поиск по названию и адресу. Тарифы одного отеля объединены в одно место. При выборе нового отеля карта переключается на него. Для города выбранного события учитывается его страна; при смене направления прежняя страна не добавляется.
- При наличии `bootstrap.maps.embed_api_key` используется официальный Embed API. Без ключа работает Google Maps iframe `output=embed`, проверенный в браузере. Это зависимый от внешнего сервиса запасной вариант; для управляемой промышленной интеграции следует настроить ограниченный браузерный ключ Google Maps Embed API. [Официальная документация](https://developers.google.com/maps/documentation/embed/embedding-map).
- До входа загружается только публичный bootstrap. Чат, карта, профиль и история отсутствуют в DOM; backend также требует авторизацию для business API. История и предпочтения доступны после входа на другом устройстве. Выход и protected API 401 размонтируют весь приватный интерфейс. Пароль хранится только в памяти формы.
- Потерянный ответ входа/выхода сверяется с сервером. При изменении аккаунта очищаются старые повторы запросов. Запоздалые 401/bootstrap прежнего аккаунта не меняют новый вход. Неудачная загрузка предпочтений не разрешает отправить старые данные.
- Выбор события отправляет его ID и версию списка; город и дата видны до нажатия.
- Потерянный запрос повторяется с исходным ID. После временной доменной ошибки новый ID создаётся только по явному нажатию. Состояние поездки применяется целиком после загрузки снимка.
- История старого режима продолжается через серверный `/continue`; старые предложения не выдаются за свежие.
- Черновики, подсказки и распознанный голос отправляются только по действию пользователя. Выход отменяет запись без отправки; запоздалое разрешение микрофона не запускает запись. Предпочтения сохраняются отдельной кнопкой.
