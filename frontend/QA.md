# Проверка React-интерфейса с обязательным входом

28 октября 2026. Актуальная сборка: `index-3vdsJd9P.js`, `index-DOTCrC78.css`. Открытых воспроизводимых ошибок в проверенном интерфейсе: **0**.

## Автоматические проверки

- TypeScript и production build Vite проходят.
- После полного прогона изменены только подписи ожидания: нейтральные «Я разбираюсь в вашем запросе» / «Я продолжаю работать над запросом», без обещания поиска во время уточнений. Production build повторно прошёл.
- **28 unit-проверок**: форматирование денег/дат/условий, категории мест, реальные координаты, Google URL, объединение тарифов одного отеля, страна события, содержательные названия сохранённых концертов, deadline HTTP, повреждённый ответ, 401 и запоздалые ответы прежнего аккаунта.
- **45 Playwright-сценариев** проходят полным прогоном. Покрыты выбор компонентов, неполный план, кнопка «Оформить» без транзакции, события/карта, история/предпочтения, регистрация/вход/выход, обязательный auth gate, ошибки сети и сессии, запись голоса при выходе, безопасное отображение текста и адаптивность.
- **5 axe-аудитов** WCAG 2 A/AA и 2.1 AA: старт после входа, выбранный план, мобильный план, экран входа и мобильная регистрация. Нарушений не обнаружено.
- Проверены 320, 390, 768, 1024 и 1440 px. Горизонтального переполнения нет. Форма регистрации на 320 × 568 прокручивается до кнопки; сообщение в планировщике доступно.
- Gate проверен со старым приватным ID в localStorage: до входа выполняется только bootstrap. Чат, карта, предложения, профиль и история отсутствуют в DOM; Escape не открывает приложение.
- 401 от отправки сообщения, профиля, истории и опроса задачи возвращает gate без старых поездок/диалогов/повторов.
- Задержанный 401 прежнего аккаунта не завершает новую сессию. Задержанный bootstrap не перезаписывает новый CSRF/user.
- Выход во время записи не отправляет аудио. Разрешение микрофона, пришедшее после выхода, сразу останавливает track и не запускает запись. Оба случая также независимо воспроизведены backend-агентом.
- **12/12 checkpoints на настоящем обновлённом сервере 8780**: обязательный gate без приватных запросов, серверный отказ анонимному профилю/истории, регистрация, сохранение пожеланий, уточнение общего концертного запроса без случайных карточек, reload разговора, неверный/верный пароль в другом браузере, восстановление истории/предпочтений на телефоне, выход+reload, реальный mid-session 401 и отсутствие JavaScript-ошибок.

## Исправленные ошибки

| Ошибка | Исправление |
| --- | --- |
| Гостевой интерфейс позволял пользоваться приложением без аккаунта | Обязательный отдельный экран входа/регистрации; приватный Planner монтируется только для user |
| При завершении сессии могли оставаться старые данные | Глобальная обработка protected API 401 размонтирует Planner, его модальные окна и состояние |
| Поздний ответ старого аккаунта мог сбить новый вход | Auth revision, проверка токена запроса и порядка bootstrap |
| Выход вызывал onstop и отправлял запись | Обработчики отключаются перед stop; поздний getUserMedia и transcribe защищены mounted guard |
| Потеря ответа login/logout оставляла старый CSRF | Сверка состояния с bootstrap и восстановление подтверждённого входа/выхода |
| Failed GET профиля оставлял старые поля доступными для сохранения | Поля очищаются, сохранение возможно только после успешной загрузки |
| Migration remap сохранял повтор старой session_id | Смена identity размонтирует всё приватное состояние |
| Старые события назывались одинаково «Концерт» | При наличии реального artist он используется в карточке, выбранном событии и тексте выбора |
| Generic concert shortcut мог выглядеть как готовый поиск | UI сохраняет исходный общий черновик без артиста; уточнения выполняет агент |
| Индикатор ожидания обещал подбор даже на этапе уточнений | Нейтральный текст работы над запросом и постоянная поясняющая подпись пустой области вариантов |
| Тарифы одного отеля дублировали точки карты | Объединение по hotel_id, иначе реальным координатам/названию/адресу |
| Карта не переходила на выбранный отель | Новое выбранное место становится активным; ручной выбор города сохраняется между вкладками |
| Одноимённый город открывался неоднозначно | Страна события добавляется только при совпадении города направления |
| Hotel-only план показывал ненужный город отправления | Origin скрыт для products=[hotel] |
| selected_event:null возвращал старое событие | Явный null не заменяется предыдущим значением |
| Результат задачи смешивался со старым request | Применяется целиком загруженный снимок |
| История старого режима не продолжалась корректно | Серверный continue сохраняет запрос/диалог и переводит сессию в текущий режим |
| «1 звезды», «6 варианта», внутренние коды мест, слабый контраст | Исправлены подписи и цвета, проверены форматтерами и axe |
| Демо-заказ был частью основного UX | Удалён; «Оформить» только отмечает сохранённый план без заказа, оплаты или заявлений о бронировании |
