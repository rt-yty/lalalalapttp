# Проверка приложения «О!дин запрос»

**Этот отчёт описывает предыдущий прогон до пользовательской проверки.** После неё обнаружены пробелы в карте, авторизации, выборе событий и интерфейсе. Текущие исправления и результаты повторной проверки находятся в [CORRECTIONS_REPORT.md](CORRECTIONS_REPORT.md). Демонстрационное оформление и карта-схема из описания ниже больше не относятся к основному интерфейсу.

Дата: 28 октября 2026, Москва. Этот отчёт относится к новой совместной версии React + FastAPI + Postgres и заменяет промежуточный статус в `output/agent-audit-2026-10-28/REPORT.md`.

## Результат

Приложение собрано и запущено на http://127.0.0.1:8780. Поиск использует настоящую модель и живые данные; оформление демонстрационное. Отдельный запуск без сети воспроизводит архив Москва — Ереван. В основной запуск входит отдельный локальный Postgres; Redis не требуется.

Финальная сводная проверка завершена: **1100 Python-проверок пройдены, без падений и пропусков**, включая настоящий Postgres; **16 frontend unit-проверок и 24 браузерных сценария пройдены**. В трёх проверенных состояниях интерфейса автоматическая проверка доступности не нашла нарушений. Дополнительно пройдены 14 этапов сквозного браузерного сценария и живые поиски, описанные ниже.

**Открытых воспроизведённых дефектов в проверенном объёме: 0.** Найденные ошибки исправлены и проверены повторно. Итоговый вопрос о выборе и расходах повторён через перезапущенное приложение с настоящей моделью: автобус 6 900 ₽, итог 6 900 ₽, неоценённые расходы указаны отдельно; ошибок браузера нет. Машинный результат общего прогона: `output/final-audit/python-junit.xml`. Детальные отчёты: `frontend/QA.md`, `output/final-audit/AGENT_QUALITY_REPORT.md`.

## Границы готовности

Поддерживаемый хакатонный сценарий — одна точка назначения, дорога туда-обратно и/или отель, RUB, гостевой профиль этого браузера, демонстрационная покупка. Не реализованы реальные платежи, аккаунты между устройствами, односторонние и многогородные маршруты, конкретные железнодорожные/автобусные места, детские наземные тарифы, навигационная карта и оценённые трансферы. При таких запросах агент обозначает ограничения. Микрофон требует разрешения пользователя; тесты не имитируют качество каждой возможной записи.

Нативный Postgres и локальное приложение проверены. Dockerfile и Compose подготовлены, но Docker отсутствует на этом компьютере, поэтому сборка контейнера не подтверждена. Сервер рассчитан на один процесс, с ограничением числа одновременно исполняемых запросов; распределённая очередь и Redis для этого объёма не нужны.

Свободный язык даёт неограниченное число вариантов ввода. Нулевой список найденных дефектов относится к описанным проверкам и не означает математической гарантии для любой будущей фразы или доступности внешних источников.
